# ADR 003: マルチバックエンド同期アーキテクチャの採用

## ステータス
提案中

## 背景
ユーザーによって同期に求める優先順位（プライバシー、利便性、画像保持、設定の簡便さ）が異なるため、単一の同期手法ではなく、複数のバックエンドから選択可能なアーキテクチャを採用する。

## 提案：同期ファサード（Facade）によるバックエンドの抽象化
`SyncManager` が直接特定のAPIを叩くのではなく、共通のインターフェースを持つ `SyncProvider` を介して同期を行う。

### 1. 同期プロバイダーの比較

| バックエンド | 特徴 | 画像同期 | 設定コスト | 権限維持 |
| :--- | :--- | :---: | :---: | :---: |
| **Local Folder** | ローカル重視 (OneDrive等) | ◯ | 中 | ✕ (都度許可) |
| **Google Drive** | 利便性重視 (Native API) | ◯ | 低 | ◎ (永続) |
| **Bookmark** | 設定ゼロ重視 (寄生型) | ✕ | 最小 | ◎ (永続) |

### 2. 抽象インターフェース (SyncProvider)
全てのプロバイダーは以下のメソッドを実装する：

```javascript
interface SyncProvider {
  /** リモートの変更をローカルに反映 */
  async pull(storage): Promise<SyncResult>;
  
  /** ローカルの変更をリモートに反映 */
  async push(storage): Promise<SyncResult>;
  
  /** 外部（他デバイス）からの変更を監視開始 */
  async watch(callback): void;
  
  /** バックエンド固有の接続設定（フォルダ選択、OAuth等） */
  async connect(): Promise<boolean>;
}
```

### 3. 実装の進め方（既存コードへの影響を最小限にする）

#### A. SyncManager のリファクタリング
`sync-manager.js` を、現在の設定（`syncMode: 'drive' | 'folder' | 'bookmark'`）に基づいて適切なプロバイダーを呼び出すオーケストレーターに変更する。

#### B. 既存ロジックの移行
- `folder-sync.js` のロジック -> `LocalFolderProvider` へ。
- `drive-sync.js` のロジック -> `GoogleDriveProvider` へ。
- 新規 -> `BookmarkProvider` を作成。

#### C. 設定UIの拡張
設定パネルに「同期方式の選択」を追加。選択された方式に応じて、フォルダ選択ボタンやログインボタンを動的に表示する。

## 4. バックエンド切り替え時のデータ移行
ユーザーが同期方式を切り替えた際、データの整合性を保つために以下の「移行同期」フローを提供する。

### 同期モード変更時の挙動
1. **IndexedDBをハブとする**: 全てのプロバイダーは IndexedDB を唯一のローカル・ソース・オブ・トゥルース（真実のソース）として扱う。
2. **初回アップロード要求**: 新しいバックエンド（例: Google Drive）に切り替えた直後、現在の IndexedDB 内の全データをそのバックエンドへ一括送信（Push）することを提案する。
3. **リモート優先マージ**: すでにバックエンドにデータが存在する場合、IDとタイムスタンプに基づいたマージを行い、 IndexedDB を更新する。

これにより、「自宅では Local Folder を使い、外出先では一時的に Google Drive を経由させる」といった柔軟な運用が可能になる。

## 5. メリット
- **ユーザーの自由度**: 権限確認を嫌う人は Google Drive/Bookmark を、クラウドにデータを置きたくない人は Local Folder を選択できる。
- **拡張性**: 将来的に Dropbox や WebDAV など、新しい同期先を簡単に追加できる。
- **堅牢性**: 内部のストレージロジック (IndexedDB) と同期ロジックが分離されるため、メンテナンス性が向上する。

## トレードオフ
- **実装の複雑化**: 各プロバイダーでの差分検出（マージロジック）を適切に実装する必要がある。
- **UIの煩雑化**: 各方式に応じた設定項目が必要。
