まずは、現在のフォルダ同期における権限チェックと要求のロジックがどこに実装されているかを確認します。ブラウザ拡張機能（特にFile System Access APIを使用している場合）では、バックグラウンドでの自動同期中に権限が切れた際、ユーザーのジェスチャーなしに直接権限を再取得することはできません。そのため、パネル（UI）側でアクションを促す必要があります。

以下のファイルを中心に調査を進めます：
- `js/folder-sync.js`: フォルダ同期のコアロジック
- `js/sync-manager.js`: 同期管理
- `js/background-handlers.js`: メッセージングとバックグラウンド処理
- `js/panel-actions.js` または `js/panel-ui.js`: ユーザーへの通知やポップアップ表示

まず、ファイル構成を再確認します。
