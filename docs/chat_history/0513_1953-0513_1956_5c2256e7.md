## ASSISTANT
お待たせしました。原因が特定できました。

Chrome拡張機能の仕様（i18n）において、`messages.json` 内で `$COUNT$` や `$TIME$` のような変数をプレースホルダーとして使用する場合、同じキー内に `placeholders` オブジェクトを記述して変数の実体（引数のマッピング）を定義しなければなりません。

`zh_CN/messages.json` の以下の3箇所で変数が使用されていますが、定義が不足しているため、Chromeがマニフェストとロケールファイルの解析に失敗しています。

**問題の箇所:**
1. `confirmAddAllTabs` (`$COUNT$` を使用)
2. `confirmOpenAllLinks` (`$COUNT$` を使用)
3. `lastSync` (`$TIME$` を使用)

正しくは以下のように記述する必要があります。

```json
    "confirmAddAllTabs": {
        "message": "将 $COUNT$ 个标签页添加到此收藏吗？",
        "placeholders": {
            "COUNT": {
                "content": "$1"
            }
        }
    },
```

運用規則（Edit Gate）に従い、このターンでの勝手なファイル編集は行っていません。
こちらで `zh_CN/messages.json` の構文を修正してよろしいでしょうか？ また、英語 (`en`) と日本語 (`ja`) の `messages.json` を確認したところ、これらは6項目しか存在しておらず、翻訳の進捗に大きな乖離があるようです。今回はまず `zh_CN` のエラー修正のみを行う形で進めてよろしいでしょうか。指示をお願いします。
