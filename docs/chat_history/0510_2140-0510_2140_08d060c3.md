## ASSISTANT
MicrosoftによるEdgeの「コレクション」機能およびサイドパネルの一部機能の廃止・縮小方針について、2026年に向けた段階的な廃止が計画されている事実を確認しました。

この機能の代替として、Chromium（Edge/Chrome）の「Side Panel API」を最大限に活用し、同様のユーザー体験を提供する拡張機能について、技術的な観点から以下の3つのカテゴリーで調査・整理しました。

### 1. コレクション・ブックマーク特化型
Edgeのコレクションに最も近い、情報の保存と整理に特化したものです。
- **Raindrop.io**: サイドパネルでの表示に対応しており、リンク、画像、PDFの保存、タグ付け、フォルダ管理が可能です。Edgeのコレクションよりも多機能であり、クロスプラットフォームでの同期も安定しています。
- **Tablerone**: タブ管理とブックマークを統合した拡張機能です。サイドパネルでセッションを保存・整理でき、視覚的なコレクション作成に適しています。

### 2. 汎用サイドパネル拡張
サイドパネル内に任意のウェブサイトや機能を配置できるものです。
- **Side Panel for Microsoft Edge (あるいは Chrome)**: 特定のアプリではなく、任意のURLをサイドパネルにピン留めできる汎用的な拡張機能です。これにより、NotionやGoogle Keepなどをサイドパネルに常駐させ、擬似的にコレクション機能として運用できます。
- **SidePanel - Bookmark Manager**: サイドパネル専用のブックマークインターフェースを提供します。標準のブックマークよりもアクセス性が高く、ドラッグ＆ドロップによる整理が可能です。

### 3. タブ・ワークスペース管理型
プロジェクトごとに情報をまとめる用途に適しています。
- **Workona**: タブを「リソース」として保存・整理する機能があり、サイドパネルからの操作が可能です。
