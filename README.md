# Web Collections

Chromium系ブラウザで動作する、コレクション管理拡張機能。
Googleアカウントの同期機能、または指定したローカルフォルダを使用してデータを保存・同期する。

## 機能

### 1. ブックマーク同期 (Googleアカウント同期)
- Chromeの標準ブックマーク同期機能をデータ転送層として利用。
- `[WC] Web Collections` フォルダ配下に、メタデータを付与したブックマークとしてデータを保存し、デバイス間で同期する。

### 2. ローカルフォルダ同期
- OneDriveやGoogle Drive等の同期フォルダを、File System Access APIを使用して指定可能。
- データをJSON形式で保存し、デバイスIDに基づく競合管理を行う。

### 3. レンダリング・表示
- `content-visibility: auto` および `contain-intrinsic-size` による、大量アイテム表示時の負荷抑制。
- `requestAnimationFrame` を用いた段階的描画による、初期表示時のUIフリーズの回避。
- `loading="lazy"` による画像リソースの読み込み制御。
- アイテムのコンテンツ量や画像のアスペクト比に依存しない、動的な高さの維持。
- ダークモードとライトモードの切り替え。
- リスト表示とタイル表示の切り替え。

### 4. 基本操作
- サイドパネルでの動作。
- ドラッグ＆ドロップによるアイテムの並べ替え（オートスクロール対応）。
- コンテキストメニュー（右クリック）からのページ・画像の追加、メモの付与。

## インストール

1. リポジトリをクローンまたはダウンロード。
2. `chrome://extensions/` を開く。
3. デベロッパーモードを有効化。
4. 「パッケージ化されていない拡張機能を読み込む」から、本ディレクトリを選択。

## 同期設定

### ブックマーク同期
デフォルト設定。Chromeのブックマーク同期が有効な場合に動作する。

### ローカルフォルダ同期
1. 設定から「同期方法」を「ローカルフォルダ」に変更。
2. 「フォルダを選択」から、任意の同期フォルダを指定。
