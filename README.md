# Web Collections

Chromium系ブラウザで動作する、Microsoft Edge「コレクション」の代替拡張機能です。
ベンダーロックインを回避し、ローカルフォルダ（OneDrive/Google Drive/Rclone同期対応）経由でデータを完全にユーザーが制御できる設計となっています。

## 特徴

### 1. Refined Modern UI
- **モノトーン・ミニマリズム**: 無駄を削ぎ落としたテクニカルで洗練されたデザイン。
- **ライト/ダークモード**: システム設定または手動切り替えに対応。
- **柔軟なレイアウト**: グリッド表示とリスト表示をワンクリックで切り替え可能。タイルサイズも調整可能。

### 2. ローカルフォルダ同期 (フォルダ共有)
- **プライバシー重視**: 独自のクラウドサーバーは使用しません。
- **フォルダ連携**: OneDrive、Google Drive、Dropbox、Rclone、など同期フォルダを指定することで、デバイス間での自動・手動同期を実現します。
- **自動デバイス識別**: デバイス名とIDを自動生成し、競合を避けた安全な同期を行います。

### 3. 操作性
- **サイドパネル対応**: ブラウザの右側に常駐し、ブラウジングを妨げません。
- **ドラッグ＆ドロップ**: 直感的な並べ替えとオートスクロールに対応。
- **クイックアクション**: ページの保存、画像の右クリック保存、メモ追加が可能。

## インストール

1. 本リポジトリをダウンロードまたはクローンします。
2. `chrome://extensions/` を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」から、本ディレクトリを選択します。

## 同期のセットアップ

1. 設定（歯車アイコン）から「フォルダを選択」をクリックし、同期に使用したいフォルダ（クラウドストレージの同期フォルダ内を推奨）を選択します。
2. 「今すぐエクスポート/インポート」ボタン、または起動時の自動同期により、デバイス間でデータが共有されます。
