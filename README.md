# Web Collections

Chromium系ブラウザで動作するコレクション管理拡張機能。
Googleアカウントの同期機能、またはGoogleドライブの専用保存領域を使用してデータを安全に保存および同期する。

## 機能

### 1. Googleドライブ同期と強固なセキュリティ
- Googleドライブ上のアプリ専用領域に、単一ファイルをアップロードして同期する。
- 同期データはブラウザ標準の機能で圧縮され、さらにAES-GCMによって自動的に暗号化される。
- セキュリティ保護のため、暗号化は常に有効となる。

### 2. ビューポート基準のオンデマンド画像ロード
- 全ての画像を事前に一括ダウンロードするのではなく、画面に表示されているアイテムを中心に前後20件の画像のみをオンデマンドで取得する。
- 不要なネットワークトラフィックを削減し、ロード時間を高速化する。

### 3. 3段階の画像フォールバックロード
- 画像を表示する際、以下の順序で段階的にデータを取得する。
  1. ローカルキャッシュ：IndexedDBに保存されているWebP形式のリサイズ済みデータを取得する。
  2. 直リンク：画像のオリジナルURLから直接ロードし、成功時は自動的にWebPへリサイズしてローカルキャッシュへ保存する。
  3. Googleドライブ：直リンクから取得できない場合、Googleドライブ上に暗号化保存されているキャッシュ画像からダウンロード、復号して表示する。

### 4. 画像インデックスの自動修復と再構築
- ドライブ上に画像インデックスファイルが存在しない場合、ドライブ上の画像ファイルを全スキャンしてインデックスを自動で再作成する自己修復機能を備える。
- 設定画面の「ドライブから画像インデックスを再構築」ボタンから、手動で明示的にスキャンと再構築を実行することもできる。

### 5. レンダリングおよび表示
- ブラウザの最適化機能である content-visibility と contain-intrinsic-size を活用し、大量アイテム表示時の負荷を抑制する。
- requestAnimationFrame を用いた段階的描画により、初期表示時のUIフリーズを回避する。
- loading属性にlazyを指定し、画像リソースの読み込みを制御する。
- アイテムのコンテンツ量や画像のアスペクト比に依存しない、動的な高さを維持する。
- ダークモードとライトモードの切り替えに対応する。
- リスト表示とタイル表示の切り替えに対応する。

### 6. 基本操作
- サイドパネルで動作する。
- ドラッグ＆ドロップによるアイテムの並べ替えに対応する。オートスクロールも機能する。
- コンテキストメニューから、ページ、画像、メモを追加できる。

## インストール

1. リポジトリをクローンまたはダウンロードする。
2. chrome://extensions/ を開く。
3. デベロッパーモードを有効化する。
4. 「パッケージ化されていない拡張機能を読み込む」から、本ディレクトリを選択する。

## 同期設定

### Googleドライブ同期
1. サイドパネルヘッダーまたは設定画面の「Googleドライブと同期」ボタンをクリックする。
2. GoogleアカウントでのOAuth認証を承認することで、アプリ専用領域との同期が自動的に開始される。
