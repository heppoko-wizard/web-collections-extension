# Web Collections

Chromium系ブラウザで動作するコレクション管理拡張機能。
Googleアカウントの同期機能、または指定したローカルフォルダを使用してデータを保存および同期する。

## 機能

### 1. ブックマーク同期。Googleアカウント同期。
- Chromeの標準ブックマーク同期機能をデータ転送層として利用する。
- Web Collections専用のフォルダ配下に、メタデータを付与したブックマークとしてデータを保存し、デバイス間で同期する。

### 2. ローカルフォルダ同期
- OneDriveやGoogle Driveなどの同期フォルダを、File System Access APIを使用して指定できる。
- データをJSON形式で保存し、デバイスIDに基づく競合管理を行う。

### 3. レンダリングおよび表示
- ブラウザの最適化機能である content-visibility と contain-intrinsic-size を活用し、大量アイテム表示時の負荷を抑制する。
- requestAnimationFrame を用いた段階的描画により、初期表示時のUIフリーズを回避する。
- loading属性にlazyを指定し、画像リソースの読み込みを制御する。
- アイテムのコンテンツ量や画像のアスペクト比に依存しない、動的な高さを維持する。
- ダークモードとライトモードの切り替えに対応する。
- リスト表示とタイル表示の切り替えに対応する。

### 4. 基本操作
- サイドパネルで動作する。
- ドラッグ＆ドロップによるアイテムの並べ替えに対応する。オートスクロールも機能する。
- コンテキストメニューから、ページ、画像、メモを追加できる。

## インストール

1. リポジトリをクローンまたはダウンロードする。
2. chrome://extensions/ を開く。
3. デベロッパーモードを有効化する。
4. 「パッケージ化されていない拡張機能を読み込む」から、本ディレクトリを選択する。

## 同期設定

### ブックマーク同期
デフォルトの設定である。Chromeのブックマーク同期が有効な場合に動作する。

### ローカルフォルダ同期
1. 設定から「同期方法」を「ローカルフォルダ」に変更する。
2. 「フォルダを選択」から、任意の同期フォルダを指定する。
