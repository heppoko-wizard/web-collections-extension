### 提案：ハイブリッド型タイトル抽出の実装案

汎用的な拡張機能としての実用性を維持しつつ、ご提示いただいたWebサイトのようなSPAサイトでも正しいタイトルを保存できるようにするため、以下の**ハイブリッド方式**の実装を提案します。

#### 1. 処理フローの設計
- まず、通常通り `fetchPageTitle` を用いてリンク先HTMLからタイトル抽出を試みます。
- もし取得できたタイトルが `| Hitomi.la` のように「ドメイン名のみ」である場合、あるいは空文字や特定の仮タイトルのパターンに一致する場合にのみ、URLの末尾セグメントからタイトルを抽出する処理を適用します。

#### 2. URLからのタイトル抽出処理（ロジック例）
`js/background.js` に以下のようなヘルパー関数を追加し、URLから日本語タイトルをデコードして整形します。

```javascript
function extractTitleFromUrl(url) {
    try {
        const parsedUrl = new URL(url);
        // パス名から最後のセグメントを取得
        let lastSegment = parsedUrl.pathname.substring(parsedUrl.pathname.lastIndexOf('/') + 1);
        if (!lastSegment) return null;

        // URLデコードを実行（例: %E3%81%86%E3%81%8... を 日本語 に変換）
        let decoded = decodeURIComponent(lastSegment);

        // 不要な部分のトリミング処理
        // 末尾の拡張子 .html または .htm を除去
        decoded = decoded.replace(/\.html?$/i, '');
        // 末尾のハイフンと数字ID（例: -3950286）を除去
        decoded = decoded.replace(/-\d+$/, '');

        return decoded || null;
    } catch (error) {
        console.warn('Failed to extract title from URL:', error);
        return null;
    }
}
```
